# 양식 A 컬럼 설명 (초안)

> **가칭 안내:** 아래 컬럼명은 모두 가칭이다. 실제 이름으로 바꿀 때는 이 문서, `tools/make_fake_data.py`가 만드는 가짜 엑셀의 헤더(T009), `config/column_map.csv`(T011) 세 곳을 같이 바꾼다. 바꾼 뒤에는 `[가칭]` 표시를 지운다.
> 값은 쓰지 않는다. 컬럼 이름과 값의 형태만 쓴다.

## 시트·헤더
- 시트 수: 1개
- 헤더 행: 1행
- 병합 셀: 없음
- 빈 행: 있음 (입력 행 수에서 빈 행을 제외하는 규칙 시험 대상, FR-014)

## 컬럼 목록 (왼쪽부터)

| 순서 | 컬럼명 | 의미 | 값의 형태 | 표준 컬럼 | 비고 |
|---|---|---|---|---|---|
| A | [가칭] 설비코드 | 설비를 구분하는 코드 | 코드 모양은 모름(확인 필요). 앞뒤 공백이 섞여 들어옴 | 설비 | 변환표로 설비명 변환 |
| B | [가칭] 에러코드 | 발생한 오류의 코드 | (확인 필요) | 없음 | '기타 항목'에 `이름: 값`으로 보관 |
| C | [가칭] 증상 | 나타난 증상 | 자유 문장 | 증상 | |
| D | [가칭] 원인 | 원인 | 자유 문장 | 원인 | |
| E | [가칭] 조치내용 | 한 조치 | 자유 문장 | 조치 | |
| F | [가칭] 부품분류 | 관련 부품의 분류 | (확인 필요: 값 종류가 몇 가지인지) | 분류 | 변환표로 표준 분류명 변환 |

- **일자 컬럼이 없다.** 표준 컬럼 '일자'는 양식 A에서 비워 둔다. 명세상 일자가 빈 것은 '확인 필요'가 아니다(FR-013).

## 규칙으로 판단하기 어려운 경우
- 설비코드가 빈 칸이거나 변환표에 없는 행: '확인 필요'
- 부품분류가 변환표에 없는 행: '확인 필요'
- 증상·원인·조치내용이 빈 행: '확인 필요'
- 완전히 빈 행: 제외 (FR-014)
- 날짜 컬럼 없음: 날짜 통일(FR-011)은 양식 A로 시험할 수 없다.
- **중복 의심(결정):** 일자가 모두 비어 있으므로 설비·증상이 같은 행은 '중복 의심'으로 표시한다. 명세 FR-010을 바꾸지 않고 그대로 적용한 결과이며, 행은 지우지 않는다. `A_basic`·`A_trap` 가짜 데이터에 설비·증상이 같은 행 쌍을 넣어 시험한다(T017).
