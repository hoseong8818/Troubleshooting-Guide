# 양식 B 컬럼 설명 (초안)

> **가칭 안내:** 아래 컬럼명은 모두 가칭이다. 실제 이름으로 바꿀 때는 이 문서, `tools/make_fake_data.py`의 양식 B 헤더(T039), `config/column_map.csv`(T040) 세 곳을 같이 바꾼다. 바꾼 뒤에는 `[가칭]` 표시를 지운다.
> 값은 쓰지 않는다. 컬럼 이름과 값의 형태만 쓴다.
> 양식 A(`docs/columns-A.md`)와 컬럼 이름이 하나도 겹치지 않는다. 양식 판별(FR-017)이 명확해진다.

## 시트·헤더
- 시트 수: 1개 (가짜 데이터에서는 숨긴 시트가 따로 있을 수 있다)
- 헤더 행: 1행
- 병합 셀: 없음
- 빈 행: 있음

## 규칙으로 판단하기 어려운 경우
- 일자가 빈 칸: '확인 필요'가 아니다(FR-013). 일자에 값이 있는데 날짜로 읽을 수 없으면 '확인 필요'.
- 설비가 빈 칸이거나 변환표에 없음: '확인 필요'
- 부품구분이 변환표에 없음: '확인 필요'. 빈 칸은 '확인 필요'가 아니다.
- 고장내용·고장원인·처리결과가 빈 칸: '확인 필요'
- 완전히 빈 행: 제외
- **다른 파일과의 중복 비교:** 설비·일자·증상이 같은 행은 파일이 달라도 '중복 의심'(FR-010). 양식 A는 일자가 비어 있어 A와 B 사이에서는 일자가 달라 중복으로 잡히지 않는다. B끼리는 잡힌다.

## 가짜 데이터에서 시험할 것 (T039)
- B 파일 3개: 정상·날짜 형식 위주(`B_basic`), 다른 파일과 중복되는 행 포함(`B_more`), 판단이 안 되는 행 위주(`B_trap`)
- 양식 A 파일 2개(`A_basic`, `A_trap`)와 합쳐 파일 5개, 양식 2종
