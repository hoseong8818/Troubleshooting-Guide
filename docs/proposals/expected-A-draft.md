# 양식 A 정답 초안 (T010, 사람이 한 행씩 검토·확정)

이 문서는 초안이다. `expected/*.xlsx`는 사람이 확정한다. 아래 "먼저 정해야 할 것"에 답하기 전에는 표의 해당 칸이 바뀔 수 있다.

## 먼저 정해야 할 것 (제가 임시로 가정한 값)

| # | 항목 | 임시 가정 | 근거 |
|---|---|---|---|
| 1 | 설비 표준 값 | 변환표의 표준 값은 앞뒤 공백을 뺀 대문자 코드(`cnv01`→`CNV01`) | T011에서 확정 |
| 2 | 분류 표준 값 **(확정)** | 등록된 분류는 자기 자신. 표기가 다른 입력 `모타`→`모터`, `SENSOR`→`센서`, ` Bearing`→`베어링`으로 변환(FR-004). A_basic 원본 행 4·7·9에 해당 | 2026-11-12 사람이 확정. 가짜 데이터 재생성 필요 |
| 3 | 텍스트 앞뒤 공백 **(확정)** | 출력에서 뺀다(`" 소음 발생 "`→`소음 발생`). 증상에서 확정했고 원인·조치내용에도 같은 처리를 적용하는 것으로 둔다(현재 가짜 데이터에는 해당 값 없음) | 2026-11-12 사람이 확정. 명세에는 출력 공백 규칙이 없어 spec 반영 후보 |
| 4 | 확인 필요 이유 문구 **(확정)** | `설비 코드 빈 칸`, `설비 코드 미등록`, `분류 미등록`, `증상 빈 칸`, `원인 빈 칸`, `조치 빈 칸`, `일자 해석 불가` | 2026-11-12 사람이 확정. 테스트가 이 문자열에 묶인다 |
| 5 | 원래 값에서 빈 칸 표기 **(확정)** | `설비: (빈 칸)` | 2026-11-12 사람이 확정. 실제 값이 `(빈 칸)`인 경우와는 구분되지 않음 |
| 6 | 원본 파일 열 **(확정)** | 실제 파일명(`A_basic.xlsx`) | 2026-11-12 사람이 확정. NFR-009의 마스킹은 로그·감사 결과에만 적용. 실제 데이터에서는 통합 시트에 실제 파일명이 들어가므로 결과 파일을 다른 사람에게 줄 때 주의(README '남은 위험' 후보) |
| 7 | 원본 시트 열 **(확정)** | 실제 시트명(`시트1`) | 6번과 같은 결정 |
| 8 | 중복 의심 칸 표시 **(확정)** | 같은 묶음의 모든 행에 `중복 의심`, 아니면 빈 칸. 묶음 번호는 두지 않는다 | 2026-11-12 사람이 확정. 묶음 구분이 필요해지면 열을 더한다 |
| 9 | 수식 방지 접두사 **(확정)** | 값 앞에 `'`를 글자로 붙인다(`'=1+1`). 엑셀의 인용 접두사 속성(`quotePrefix`)은 쓰지 않는다 | 2026-11-12 사람이 확정. NFR-008의 해석 |
| 10 | 일자 열 **(확정)** | 양식 A는 일자 대응이 없으므로 모든 행에서 빈 칸. 정렬은 설비 → 원본 파일 → 원본 행 순이 된다 | 2026-11-12 사람이 확정 |

출력 컬럼 순서: 설비, 일자, 증상, 원인, 조치, 분류, 기타 항목, 확인 필요 이유, 원래 값, 중복 의심, 원본 파일, 원본 시트, 원본 행.

## A_trap (보이는 시트 입력 6행 → 출력 6행, 숨긴 시트 2개는 읽지 않음)

정렬: 설비가 정상인 행이 먼저(CNV01, PMP01 순), 설비가 확인 필요인 행은 맨 아래에 원본 행 순.

| 설비 | 일자 | 증상 | 원인 | 조치 | 분류 | 기타 항목 | 확인 필요 이유 | 원래 값 | 중복 의심 | 원본 파일 | 원본 시트 | 원본 행 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| CNV01 | | 확인 필요 | 과열 | 확인 필요 | 모터 | 에러코드: E104 | 증상 빈 칸; 조치 빈 칸 | 증상: (빈 칸); 조치: (빈 칸) | | A_trap.xlsx | 시트1 | 5 |
| PMP01 | | 경보 | 센서 오염 | 센서 청소 | 확인 필요 | 에러코드: E103 | 분류 미등록 | 분류: LEAK-분류 | | A_trap.xlsx | 시트1 | 4 |
| 확인 필요 | | 누유 | 씰 파손 | 씰 교체 | 밸브 | 에러코드: E101 | 설비 코드 빈 칸 | 설비: (빈 칸) | | A_trap.xlsx | 시트1 | 2 |
| 확인 필요 | | LEAK-정지 | 원인 불명 | 재기동 | 모터 | 에러코드: E102 | 설비 코드 미등록 | 설비: ZZ99 | | A_trap.xlsx | 시트1 | 3 |
| 확인 필요 | | 소음 | 확인 필요 | 점검 | 확인 필요 | 에러코드: E105 | 설비 코드 미등록; 원인 빈 칸; 분류 미등록 | 설비: ZZ98; 원인: (빈 칸); 분류: 미등록분류 | | A_trap.xlsx | 시트1 | 6 |
| 확인 필요 | | 누유 | 씰 노후 | 점검 | 밸브 | 에러코드: E106 | 설비 코드 빈 칸 | 설비: (빈 칸) | | A_trap.xlsx | 시트1 | 7 |

확인할 점
- 행 2와 7은 증상(`누유`)이 같지만 둘 다 설비가 확인 필요라 비교에서 빠져 **중복 의심이 아니다**(FR-010).
- 사유가 여러 개인 행(원본 행 6)은 FR-015의 순서(설비, 일자, 증상, 원인, 조치, 분류)와 구분자 `; `를 따른다.
- 행 3과 행 4의 `LEAK-` 값은 통합 시트에 그대로 남는다. 시험 대상은 **로그·감사 결과에 나오지 않는 것**이다(NFR-002).
- 이 파일에서는 등록된 설비도 분류가 미등록이면 설비는 정상이고 분류만 '확인 필요'다(원본 행 4).

## 감사 결과에 들어갈 내용 (참고, 별도 정답 파일 없음)

- A_basic: 입력 11행, 출력 11행, 일치, 확인 필요 0건, 중복 의심 3행, 수식 방지 접두사 4건, 기타 항목 컬럼 1개(`에러코드` 등록 여부는 T011에서 정함)
- A_trap: 입력 6행, 출력 6행, 일치, 확인 필요 6건, 숨긴 시트 2개 보고, 수식 방지 접두사 0건
