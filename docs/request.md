# 요청: 트러블슈팅 엑셀 통합 도구

이 문서는 `/speckit-specify`에 넘길 첫 요청문이다. 기술 이야기는 쓰지 않는다.
지켜야 할 원칙은 `docs/constitution.md`를 따른다.

## 왜 필요한가

설비 트러블슈팅 기록을 여러 사람이 각자 양식의 엑셀로 쓴다. 기록이 한곳에 모이지 않아서 같은 설비에서 같은 문제가 반복돼도 알아채기 어렵다. 엑셀 여러 개를 한 표로 모으고 설비별로 분류해서, 설비 기준으로 과거 기록을 한 번에 볼 수 있게 한다.

## 무엇을 하는가

양식이 다른 트러블슈팅 엑셀 파일 여러 개를 읽어 표준 컬럼의 통합 표 하나로 만든다. 설비는 설비 코드 컬럼을 기준으로 판단한다.

- **표준 컬럼 6개**: 설비, 일자, 증상, 원인, 조치, 분류
- **표준에 없는 컬럼**: 버리지 않고 '기타 항목'에 `이름: 값`으로 보관한다.
- **양식이 새로 생기면**: 코드를 고치지 않고, 파일별 컬럼 대응 규칙 표만 추가해서 처리한다.
- **분류 이름**: 변환 규칙 표로 통일한다. 표에 없는 값은 '확인 필요'로 두고 원래 값을 남긴다. 사람이 표에 한 줄을 더하면 다음 실행부터 자동으로 처리된다.
- **판단이 안 되는 행**: 억지로 분류하지 않고 '확인 필요'로 남긴다(원칙 3).

## 입력

- 트러블슈팅 엑셀 파일. 양식은 파일마다 다르다.
- 첫 번째 가짜 양식(양식 A): 시트 1개, 1행이 헤더다. 컬럼명은 실제와 같게 만든다.
- 최종 범위: 양식 2~3종, 파일 5~8개, 분류 변환 규칙 표 1개.
- 실제 엑셀은 AI가 읽지 않는다. 컬럼 구성은 사람이 쓴 설명 문서로만 전달한다(원칙 1).

## 출력

- 엑셀 파일 1개, 통합 시트 1장.
- 행은 입력의 모든 행을 빼지 않고 담는다. 입력 행 수와 출력 행 수가 같아야 한다.
- 판단이 안 되는 행에는 '확인 필요', 원래 값, 이유가 함께 나온다.
- 실행이 끝나면 감사 결과를 낸다. 매핑되지 않은 컬럼, 필수값이 빈 행, '확인 필요' 건수, 입력·출력 행 수 일치 여부다. 로그에는 셀 값을 남기지 않는다(원칙 2).

## 이번에 하지 않는 것

- 설비를 자유 텍스트에서 추정하는 일. 이번에는 설비 코드 컬럼이 있는 경우만 완성한다.
- 실제 엑셀을 AI가 읽는 일.
- 양식 2종 이상은 양식 A가 정답과 한 행씩 일치한 뒤에 늘린다.

## 아직 정하지 못한 것 (구체화 단계에서 질문으로 채운다)

- 설비 코드의 형식과, 설비 코드가 같은 행이 여러 파일에 있을 때 중복으로 볼 기준
- 날짜 형식이 여러 가지일 때 읽을 규칙과, 해석할 수 없는 날짜의 처리
- 시트가 여러 개이거나 숨긴 시트가 있을 때 처리
- 필수값으로 볼 컬럼
- '확인 필요' 행을 통합 표에서 어디에 어떻게 보여 줄지

## 완료 기준 (명세에서 수용 기준으로 구체화한다)

1. 가짜 엑셀 입력을 넣으면 정답 파일과 한 행씩 일치한다.
2. 입력 행 수와 출력 행 수가 같다.
3. 표준에 없는 컬럼의 값이 '기타 항목'에 보관된다.
4. 판단이 안 되는 행이 '확인 필요'와 원래 값으로 남는다.
5. 로그와 에러에 셀 값이 없다.
