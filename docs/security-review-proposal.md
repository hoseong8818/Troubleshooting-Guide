## 높음

### H1. "AI가 실제 엑셀을 못 읽게 한다"의 토대가 약하다 (원칙 1)

**근거**: `plan.md:113` deny는 `./data/real/**` 하나뿐이고, 실제 데이터 위치는 "미정"(`plan.md:46`, `constitution.md:13`). 팀원이 보낸 엑셀은 보통 다운로드, 바탕화면, 메일 첨부 폴더에 있다. 그 경로에는 deny가 없다. 또 도구를 AI가 실행해 `out/` 통합 엑셀을 만들면, 실제 데이터가 담긴 `out/`을 AI가 읽을 수 있다(`out/`은 deny 대상이 아니다). `--input`은 임의 경로를 받는다(`spec.md` FR-019).

**위험**: 에이전트가 `Read C:\Users\...\Downloads\팀원.xlsx`나 `out/통합.xlsx`를 읽으면 원칙 1 위반이고, 되돌릴 수 없다(요청에 실려 로컬 기록에 남음).

| 선택지 | 내용 | 비용 | 효과 |
|---|---|---|---|
| A (권장) | 실제 데이터는 **저장소 밖 고정 폴더 1곳**(예: `D:\real_data`)만 사용. 그 폴더와 `out/`, 사용자 홈의 다운로드·바탕화면까지 deny에 넣는다(Read, Grep, Glob, Bash, PowerShell). 실제 데이터에 도구를 돌리는 것은 **사람이 자기 터미널에서만**. | 낮음 | 중간. 문자열 우회는 남음(H2에서 보완) |
| B | A + `out/`도 실제 실행 결과는 저장소 밖(`D:\real_out`)에 쓰게 하고 `out/`은 가짜 데이터 전용으로 한정 | 낮음 | 중상. AI가 볼 수 있는 폴더에 실제 결과가 아예 없음 |
| C | 현 계획 유지(`data/real`만 deny) | 없음 | 낮음. 위치 규칙이 사람 기억에 의존 |

### H2. 훅과 deny는 문자열 검사라 우회가 쉽다 (원칙 1, 4)

**근거**: `plan.md:115`는 "보호 경로가 있고 쓰기 동사가 있으면 차단", `plan.md:123`은 한계를 인정하고 README에만 적는다. 쓰기 동사 목록(`cp`, `mv`, `Set-Content`, `Out-File`, `>`)에 **삭제(`rm`, `del`, `Remove-Item`), 이름 변경(`ren`), `git checkout/restore/reset/rm`, `xcopy/robocopy`, `curl -o`, `certutil`, `python -c`로 파일 열기** 등이 빠져 있다. 읽기 쪽은 더 약하다. `python -c "import openpyxl; ..."`에 경로를 문자열 연결로 만들면 deny 패턴을 지나간다.

### H6. 입력 엑셀은 "신뢰할 수 없는 파일"인데 방어가 없다 (수식 주입, 압축·XML 폭탄)

**근거**: 입력은 팀원이 보낸 엑셀이다. 명세·계획에 이를 다루는 항목이 없다.
1. **수식 주입**: openpyxl은 `=`로 시작하는 문자열을 **수식 셀로 저장**한다. 입력 셀 값이 `=HYPERLINK(...)`, `=cmd|...`이면 통합 엑셀을 여는 담당자 PC에서 실행·외부 통신이 일어날 수 있다(`+`, `-`, `@` 시작도 같은 계열).
2. **XML·압축 폭탄**: openpyxl은 `defusedxml`이 없으면 XML 확장 공격(billion laughs)과 거대 압축 해제에 취약하다고 문서화돼 있다. 한 파일이 PC를 멈출 수 있다.
3. 외부 링크·매크로(`xlsm`): 열기만 하고 따라가지 않아야 한다.

| 선택지 | 내용 | 비용 | 효과 |
|---|---|---|---|
| A (권장) | 명세에 요구사항 추가: (1) 출력 시 문자열 셀은 항상 **문자열 형식으로 쓰고** `=+-@`로 시작하면 앞에 `'` 또는 공백을 붙임 + 테스트 `test_formula_injection`, (2) 입력 파일 크기·압축 해제 크기·행 수 상한을 두고 초과 시 그 파일만 건너뛰어 감사 보고(처리 시간 상한 NFR-005와는 별개), (3) `.xlsx`만 허용, `.xlsm`·`.xls`는 '열 수 없음' 처리, 외부 링크 미추적 | 중간 | 상 |
| B | (1)과 (3)만 반영하고 (2)는 보류 | 낮음 | 중 |
| C | 현행 유지 | 없음 | 낮음 |

외부 패키지 "openpyxl 하나" 규칙(`plan.md:18`)과 `defusedxml` 사용이 충돌한다. A를 택하면 "openpyxl + defusedxml 2개"로 규칙을 고치거나, 상한 검사로만 방어하고 defusedxml은 쓰지 않는 안(비용 낮음, 효과 중) 중 정해야 한다. → 결정표 H6의 하위 질문.
